# Island — Dynamic Island для Windows

Ультра-оптимизированный виджет **Dynamic Island** для Windows в стиле чистого OLED-чёрного (`#000000`) с плавной пружинной физикой 120 Гц, векторной графикой и живой интеграцией с системой.

## Возможности
- **Медиаплеер (Windows GSMTC)**: мгновенная синхронизация таймлайна без задержек при перемотке, плавный скраббинг мышью, кнопки **Нравится / Не нравится**, перемотка `-10с / +10с`, живой эквалайзер с цветами обложки трека.
- **Микшер громкости по приложениям (WASAPI / PyCAW)**: индивидуальные ползунки громкости для каждого запущенного приложения со звуком + быстрый выбор аудиовыхода.
- **Погода (Автоопределение геолокации)**: автоматическое определение местоположения по IP, почасовой график температуры с векторными кривыми Безье, прогноз на 5 дней, радар ветра, УФ-индекс, точка росы и давление в мм рт. ст.
- **Буфер обмена, Полка файлов, Заметки и Таймер**: история скопированного текста и изображений, drag-and-drop полка файлов, быстрые заметки и секундомер/таймер.
- **Управление и OTA-обновления через GitHub**: быстрые системные утилиты (скриншот области/экрана, OCR текста с экрана, QR-генератор, пипетка цвета, очистка ОЗУ) и встроенное обновление приложения в один клик напрямую из репозитория [`sipicynaana0-cmd/Island`](https://github.com/sipicynaana0-cmd/Island).

```bat

```
