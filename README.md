# Island v2.1 — Dynamic Island для Windows (Rust Core + PyQt6)

Ультра-оптимизированный виджет **Dynamic Island** для Windows в стиле чистого OLED-чёрного (`#000000`) с нативным **Rust-ядром (`island_core.dll` v2.1)**, живыми текстами песен, эмоциональными глазками и адаптивной пружинной физикой 60–240 Гц.

## Ключевые возможности v2.1
- **Нативное Rust-ядро v2.1 (`rust_core/` → `island_core.dll`)**:
  - Батч-движок всех пружин интерфейса за один C-ABI вызов (`< 20 мкс`) с автоопределением герцовки монитора (`60–240 Гц`).
  - 2048-точечный Radix-2 FFT анализатор звука (`0.055 мс/кадр`), Win32-детектор полноэкранных игр, 1ns трекер буфера обмена, O(log N) поиск строк LRC и глобальные хоткеи (`Ctrl+Shift+I` — вызвать/скрыть Остров, `Alt+M` — быстрый Mute).
- **Живые тексты песен (Live Synced Lyrics)**: автоматическая подгрузка и пошаговая синхронизация текста трека прямо в карточке плеера (кнопка «Текст») и в сложенной капсуле.
- **Живой характер Острова (эмоции глазок)**: глазки следят за курсором и перетаскиваемыми файлами, счастливо жмурятся (`^ ^`) при поглаживании, качают в такт басу, сонно прикрываются ночью и удивляются при уведомлениях.
- **Строгий монохромный OLED-стиль и исправленный Smart Dock**: минималистичные чёрно-белые карточки быстрых действий без цветовой пестроты, стабильное добавление своих программ через `+ Добавить` с сохранением между запусками и удалением по правому клику.
