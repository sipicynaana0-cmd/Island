# Island v2.0 — Dynamic Island для Windows (Rust Core + PyQt6)

Ультра-оптимизированный виджет **Dynamic Island** для Windows в стиле чистого OLED-чёрного (`#000000`) с нативным **Rust-ядром (`island_core.dll`)**, плавной пружинной физикой 120 Гц, векторной графикой и живой интеграцией с системой.

## Ключевые возможности v2.0
- **Нативное Rust-ядро (`rust_core/` → `island_core.dll`)**: 2048-точечный Radix-2 FFT анализатор звука за `0.055 мс/кадр`, мгновенный Win32-детектор полноэкранных игр, расчёт живой волны и системная телеметрия CPU/ОЗУ на чистом Rust без сторонних зависимостей.
- **Игровой режим со стрелочкой и появлением «Точка → 2 глазика → Остров»**: при входе в полноэкранную игру остров плавно сворачивается в аккуратную стрелочку сверху экрана; по нажатию на неё (или при выходе из игры) он оживает через 3 этапа: опускающаяся точка, два моргающих глазика и раскрытие самой капсулы.
- **Полностью обновлённый интерфейс**: тонкая сложенная капсула без провисания волны, единая стеклянная шапка управления, цветная Bento-матрица быстрых действий и полноразмерный Smart Dock с векторными иконками и подписями.
- **Живые уведомления и плазменная загрузка**: фирменные капсулы уведомлений для Telegram, Discord, микрофона и наушников, обновлённое меню обновлений с 3-кольцевым гироскопом и анимированной загрузкой OTA-обновлений прямо из репозитория [`sipicynaana0-cmd/Island`](https://github.com/sipicynaana0-cmd/Island).
