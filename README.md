# Island v2.2 — Dynamic Island для Windows (Rust Core + PyQt6)

Ультра-оптимизированный виджет **Dynamic Island** для Windows в стиле чистого OLED-чёрного (`#000000`) с нативным **Rust-ядром (`island_core.dll` v2.2)**, поиском Spotlight, живыми событиями Steam/USB/CapsLock, реальными иконками программ и строгой изоляцией визуализации только на музыку.

## Ключевые возможности v2.2
- **Нативное Rust-ядро v2.2 (`rust_core/` → `island_core.dll`)**:
  - Извлечение реальных системных иконок `.exe` / `.lnk` через Win32 (`SHGetFileInfoW` + `DrawIconEx`).
  - Многодисковый сканер активных загрузок **Steam** (название игры, `%`, скорость `МБ/с`).
  - Мгновенные системные события: **CapsLock**, подключение/извлечение **USB-флешек**, загрузки из браузера.
  - Глобальные хоткеи (`Alt + Space` — **Spotlight**, `Ctrl + Shift + I` — **2 глазика**, `Alt + M` — **Mute**), безопасный Rust-калькулятор, батч-физика пружин 60–240 Гц и FFT-анализатор за `0.055 мс`.
- **Умный поиск Spotlight (`Alt + Space`)**: запуск программ из меню Пуск с настоящими иконками, встроенный калькулятор на Rust, быстрый конвертер (`100$`, `16gb`) и поиск в Google/YouTube.
- **Только музыка на волне и эквалайзере**: по-сессионная изоляция звука плеера через Windows Core Audio — Discord, игры и системные уведомления больше не двигают волну.
- **Точные тексты песен + подстройка ритма (`-0.5с / +0.5с`)**: строгая проверка названия, артиста и длительности трека (чужие песни и фейковый ритм больше не показываются).
- **Живые глазки, интерактивные уведомления и чистая вкладка «Обновления»**: глазки всегда живые, когда музыка на паузе; наведение на уведомление не раскрывает Остров поверх кнопки «Открыть»; вкладка «Обновления» содержит только обновления, а настройки вида перенесены в «Управление».
