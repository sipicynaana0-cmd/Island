# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ ПРИЛОЖЕНИЯ «Island»

## 1. Общие положения
1.1. Настоящая Политика конфиденциальности (далее — Политика) регулирует порядок обработки и защиты информации о пользователях при использовании программного обеспечения для персональных компьютеров **«Island»** (далее — Приложение), представляющего собой интерактивную системную панель («Остров») поверх окон операционной системы.

1.2. Разработчиком Приложения является **sipicynaana0-cmd** (далее — Разработчик).

1.3. Устанавливая, запуская или используя Приложение, Пользователь подтверждает, что ознакомился с настоящей Политикой и принимает её условия. В случае несогласия с условиями Политики Пользователь обязан прекратить использование Приложения и удалить его со своего устройства.

## 2. Какие данные обрабатывает Приложение
Приложение спроектировано по принципу приоритета локальной обработки данных (**Local-First**). Большая часть информации обрабатывается исключительно в оперативной памяти компьютера Пользователя и не передаётся на внешние серверы.

### 2.1. Локальные системные данные (не покидают устройство Пользователя):
* **Медиаданные:** название текущего трека, имя исполнителя, обложка альбома и состояние воспроизведения (получаются через системный интерфейс управления медиа ОС) — используются только для отображения мини-плеера на панели.
* **Системные индикаторы:** уровень громкости, яркости экрана, заряд батареи, состояние подключения периферийных и Bluetooth-устройств, состояние таймеров — используются для визуального отображения статусов.
* **Системные уведомления (при включении пользователем):** заголовок и краткий текст входящих уведомлений ОС для их показа внутри панели «Остров».
* **Состояние окон и экрана:** разрешение экрана, положение курсора в зоне панели и факт запуска полноэкранных приложений (игр, видео) — используются для корректного позиционирования и автоматического скрытия панели.
* **Пользовательские настройки:** выбранная тема оформления, размеры, анимации, список любимых треков, список исключений и параметры автозапуска — хранятся локально в папке конфигурации Приложения или реестре ОС.

### 2.2. Технические данные при обращении к сети (если функции активны):
* **Проверка и установка обновлений:** при запросе новой версии Приложение обращается к официальному репозиторию обновлений GitHub (`https://github.com/sipicynaana0-cmd/Island`). При таком запросе технически передаются текущая версия Приложения, тип ОС и IP-адрес устройства (в рамках стандартного сетевого соединения).
* **Автоматический прогноз погоды:** для отображения температуры в вашем городе Приложение определяет примерные координаты города по IP и запрашивает метеосводку у открытого сервиса Open-Meteo.
* **Отчёты об ошибках (логи сбоев):** формируются локально на диске. Передаются Разработчику только по инициативе самого Пользователя.

### 2.3. Данные, которые Приложение НЕ собирает и НЕ обрабатывает:
* пароли, платёжные реквизиты, содержимое личных файлов и документов;
* историю посещённых сайтов и нажатия клавиш вне области управления Приложением;
* аудиозаписи с микрофона, видеопоток с веб-камеры и точную GPS-геолокацию;
* персональные данные для рекламного профилирования.

## 3. Цели обработки информации
Обработка указанных технических данных осуществляется исключительно для:
1. Корректного отображения и анимации интерактивной панели «Остров» на экране ПК.
2. Синхронизации с системными событиями (медиа, громкость, батарея, уведомления).
3. Сохранения персональных настроек интерфейса Пользователя между запусками.
4. Поиска и устранения технических сбоев, а также автоматического обновления Приложения через GitHub.

## 4. Хранение, защита и передача данных третьим лицам
4.1. Локальные данные о медиа, уведомлениях и состоянии системы обрабатываются в реальном времени и не записываются в постоянное хранилище, за исключением файлов пользовательских настроек.

4.2. Разработчик не продаёт, не сдаёт в аренду и не передаёт данные Пользователей третьим лицам, рекламным сетям или аналитическим брокерам.

4.3. Доступ к данным может быть предоставлен третьим лицам исключительно в случаях, прямо предусмотренных действующим законодательством, и только в отношении тех данных, которыми Разработчик фактически располагает.

## 5. Права и управление данными со стороны Пользователя
Пользователь полностью контролирует работу Приложения и вправе в любой момент:
* отключить доступ к системным уведомлениям, медиа или проверке обновлений в настройках Приложения;
* удалить локальные файлы настроек из папки Приложения;
* полностью прекратить обработку любых данных путём удаления Приложения с ПК.

## 6. Изменение Политики и контакты
6.1. Разработчик вправе обновлять настоящую Политику при добавлении новых функций в Приложение. Актуальная версия всегда доступна внутри Приложения и в репозитории `https://github.com/sipicynaana0-cmd/Island`.

6.2. Контакты Разработчика:
